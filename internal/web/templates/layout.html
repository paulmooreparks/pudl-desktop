PUDL Desktop

PUDL Desktop is a place to write and keep Markdown documents, built with the PUDL design language. It is at an early stage: today it keeps folders and Markdown files with their full history.

A temporary workspace

A temporary workspace keeps your files on this desktop's server. It belongs to this browser alone, lasts {{.Lifetime}}, and holds up to {{.Quota}} of text. Nothing is shared, and everything is deleted when it expires.
