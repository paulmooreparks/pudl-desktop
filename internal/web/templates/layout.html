    Connect an agent

    An AI agent can work in this workspace as you do, through the same pages and forms, and you can watch its changes arrive in your windows. Give it PUDL Desktop's MCP server, with this workspace's token as a bearer token. Anyone holding the token can change this workspace until it expires, so give it only to an agent you trust with it.

    MCP endpoint{{.Endpoint}}
    HeaderAuthorization: Bearer {{.Token}}
    Workspace{{.Workspace}}

    For Claude Code, the command is:

    claude mcp add --transport http pudl-desktop {{.Endpoint}} --header "Authorization: Bearer {{.Token}}"

    Tell the agent to start at {{.Workspace}}. A plain HTTP client can send the same header to any of the workspace's pages.
